# Installation und Programmstart

## Installation {#installation}

Bei der manuellen Installation über die Eingabeaufforderung oder das Terminal wird stellenweise eine bestimmte Version genannt, etwa 4.0. Prüfen Sie auf der [Veröffentlichungsseite](https://github.com/ccbogel/QualCoder/releases), ob bereits eine neuere Version verfügbar ist.

### Voraussetzungen {#prerequisites}

VLC wird optional für das Codieren von Audio/Video benötigt. Für die Darstellung einer Wellenform können Sie zusätzlich ffmpeg installieren; siehe [Anleitung für Windows](https://phoenixnap.com/kb/ffmpeg-windows). Unter Fedora kann QualCoder beim Anzeigen oder Codieren von Audio/Video abstürzen.

=== "Windows"

    Wählen Sie die [aktuelle Veröffentlichung](https://github.com/ccbogel/QualCoder/releases/latest).

    Für die unter Windows 11 erstellten ausführbaren Dateien gibt es zwei Möglichkeiten:

    1. Verwenden Sie das Windows-Installationsprogramm von der Veröffentlichungsseite.
    2. Verwenden Sie die portable Version ohne Installation. Sie können die heruntergeladene Datei direkt ausführen. Der Programmstart kann bis zu 30 Sekunden dauern.

    Beim ersten Start meldet Windows, dass QualCoder von einem unbekannten Herausgeber stammt. Klicken Sie auf **Weitere Informationen > Trotzdem ausführen**. Ein Zertifikat für einen vertrauenswürdigen Herausgeber verursacht hohe Kosten und ist deshalb auf absehbare Zeit nicht vorgesehen. Wenn Sie sich damit nicht wohlfühlen, können Sie die Software wie unten beschrieben aus dem Quellcode installieren.

    **Installation aus dem Quellcode:**

    Verwenden Sie eine virtuelle Umgebung, wie in Schritt 6 beschrieben. Ohne diese können andere installierte Python-Programme beeinträchtigt werden.

    1. Laden Sie eine aktuelle Version von [Python 3](https://www.python.org/downloads/) herunter und installieren Sie sie. Wählen Sie den neuesten „Windows installer (64-bit)“ oder die Variante für Ihre Prozessorarchitektur.

        **Wichtig:** Aktivieren Sie im ersten Installationsfenster **Add Python to PATH**.

    2. Laden Sie QualCoder von [GitHub](https://github.com/ccbogel/QualCoder) herunter: **Code > Download ZIP**. Das ist der neueste Entwicklungsstand, der noch nicht offiziell veröffentlicht ist und gelegentlich Programmierfehler enthalten kann. Alternativ wählen Sie die ZIP-Datei der neuesten Veröffentlichung über **Releases** auf der rechten Seite.

    3. Entpacken Sie die Datei, etwa im Ordner „Downloads“. Vermeiden Sie einen doppelten Ordnerpfad wie `QualCoder-master\QualCoder-master`; wählen Sie beim Entpacken nur `QualCoder-master`.

    4. Öffnen Sie die Windows-Eingabeaufforderung, indem Sie im Startmenü nach `cmd` suchen und `cmd.exe` auswählen. Befehle können Sie eintippen oder per Rechtsklick einfügen; je nach Konfiguration funktioniert `Strg+V` dort nicht.

    5. Wechseln Sie mit `cd` in den entpackten QualCoder-Ordner, etwa `QualCoder-master` oder bei einer Veröffentlichung `QualCoder-4.0`:

        ```bash
        cd Downloads\QualCoder-master
        ```

        Statt der folgenden manuellen Befehle können Sie die Batchdatei starten, die diese Schritte ausführt:

        ```
        run_from_source_Windows.bat
        ```

        Treten dabei Fehler auf, führen Sie die folgenden Befehle einzeln aus.

    6. Erstellen Sie die virtuelle Umgebung und installieren Sie die benötigten Python-Module. Dies kann bis zu zehn Minuten dauern. Auf manchen Windows-Systemen müssen Sie `python` durch `py` oder `python3` ersetzen.

        ```bash
        python -m venv env
        env\Scripts\activate
        python -m pip install --upgrade pip
        python -m pip install -r requirements.txt
        ```

    7. Wechseln Sie in den Unterordner `src` und starten Sie QualCoder:

        ```bash
        cd src
        python -m qualcoder
        ```

    8. Nach dem Beenden von QualCoder verlassen Sie die virtuelle Umgebung mit `deactivate`. Der Zusatz `(env)` verschwindet aus der Eingabeaufforderung.

    **QualCoder erneut starten:**

    Ohne virtuelle Umgebung verwenden Sie auf demselben Laufwerk, etwa `C:`, den Befehl `python -m qualcoder`.

    Mit virtueller Umgebung wechseln Sie zunächst in den Ordner `QualCoder-master` beziehungsweise den Ordner der Veröffentlichung und führen aus:

    ```
    env\Scripts\activate
    cd src
    python -m qualcoder
    ```

=== "macOS"

    **Installation des App-Pakets:**

    Installieren Sie zunächst verfügbare macOS-Updates unter **Systemeinstellungen > Allgemein > Softwareupdate**. Gegebenenfalls müssen Sie in der Seitenleiste nach unten scrollen.

    Öffnen Sie die heruntergeladene DMG-Datei per Doppelklick und ziehen Sie QualCoder auf die Verknüpfung zum Programme-Ordner.

    Starten Sie QualCoder über das Launchpad oder per Doppelklick im Programme-Ordner. Die App-Pakete sind derzeit nicht signiert. Beim ersten Start erscheint deshalb möglicherweise eine Warnung zu einer nicht registrierten Entwickler:in oder dazu, dass Apple die App nicht auf Schadsoftware überprüfen kann.

    Je nach System bietet die Meldung **Im Finder zeigen** oder **OK** an; klicken Sie auf **OK**. Wenn Sie **Fertig** oder **In den Papierkorb bewegen** sehen, wählen Sie **Fertig**.

    Öffnen Sie anschließend **Systemeinstellungen > Datenschutz & Sicherheit**. Scrollen Sie zu der Meldung über den blockierten Start von QualCoder und klicken Sie auf **Dennoch öffnen**. Geben Sie gegebenenfalls Ihr Passwort ein und bestätigen Sie nochmals mit **Öffnen**. Warten Sie einige Sekunden, bis das Programm startet. Danach sollte es sich ohne weitere Warnung öffnen lassen.

    Auch eine Installation ohne Administrator:innenrechte ist möglich: Kopieren Sie die Programmdateien nach `/Users/mylogin/Applications` und entfernen Sie das Quarantäneattribut im Terminal. Ersetzen Sie `mylogin` durch Ihren Anmeldenamen:

    ```bash
    xattr -d com.apple.quarantine /Users/mylogin/Applications/QualCoder.app
    ```

    **Installation aus dem Quellcode:**

    Verwenden Sie eine virtuelle Umgebung, wie in Schritt 6 beschrieben. Ohne diese können andere Python-Programme beeinträchtigt werden.

    1. Laden Sie [Python 3 für macOS](https://www.python.org/downloads/macos/) herunter und installieren Sie es. Die Anleitung nennt Python 3.10, 3.11 oder 3.12; andere Versionen können Probleme verursachen. Verwenden Sie den neuesten „macOS 64-bit universal2 installer“ einer dieser Versionen.

    2. Laden Sie QualCoder von [GitHub](https://github.com/ccbogel/QualCoder) über **Code > Download ZIP** herunter. Dieser Entwicklungsstand ist noch nicht offiziell veröffentlicht und kann Fehler enthalten. Alternativ laden Sie unter **Releases** die ZIP-Datei der aktuellen Veröffentlichung herunter.

    3. Entpacken Sie die Datei per Doppelklick, etwa in „Downloads“.

    4. Öffnen Sie **Programme > Dienstprogramme > Terminal**.

    5. Wechseln Sie mit `cd` in den entpackten QualCoder-Ordner, etwa `QualCoder-master` oder `QualCoder-4.0`:

        ```bash
        cd Downloads/QualCoder-master
        ```

    6. Erstellen Sie die virtuelle Umgebung und installieren Sie die Python-Module.

        `python3` verwendet die neueste installierte Python-Version. Bei mehreren Installationen können Sie eine bestimmte Version angeben, etwa `python3.10`. Prüfen Sie mit `which python3`, welche Version verwendet wird. Der Pfad sollte `/Library/Frameworks/Python.framework/Versions/3.<version>/bin/python3` lauten. Bei `/usr/bin/python3` brechen Sie ab: Dies ist die Python-Installation des Betriebssystems, deren Nutzung hierfür nicht empfohlen wird.

        Die Installation kann bis zu zehn Minuten dauern.

        ```bash
        python3 -m venv env # Erstellt die virtuelle Umgebung "env" im aktuellen Ordner
        source env/bin/activate # Aktiviert sie; vor der Eingabeaufforderung erscheint (env)
        pip3 install --upgrade pip # Optional; pip und pip3 sind in der virtuellen Umgebung gleichwertig
        pip3 install -r requirements.txt
        ```

    7. Starten Sie QualCoder im Terminal:

        ```bash
        cd src
        python3 -m qualcoder # python und python3 sind in der virtuellen Umgebung gleichwertig
        ```

    8. Verlassen Sie die virtuelle Umgebung anschließend mit `deactivate`. Der Zusatz `(env)` verschwindet.

    **QualCoder erneut starten:**

    Ohne virtuelle Umgebung:

    ```bash
    cd Downloads/QualCoder-master
    cd src
    python3 -m qualcoder
    ```

    Mit virtueller Umgebung:

    ```bash
    cd Downloads/QualCoder-master
    source env/bin/activate
    cd src
    python3 -m qualcoder
    ```

=== "Linux"

    Für Debian-basierte Systeme wie Debian, Ubuntu, Lubuntu, ZorinOS und Linux Mint steht auf der Veröffentlichungsseite eine ausführbare Datei bereit. Laden Sie sie herunter und starten Sie sie per Doppelklick. Möglicherweise müssen Sie zuvor per Rechtsklick unter **Eigenschaften** die Ausführbarkeit aktivieren.

    Auf anderen Systemen installieren Sie QualCoder wie unten beschrieben aus dem Quellcode.

    Fedora verwendet Wayland, das mit der grafischen Qt-Oberfläche Schwierigkeiten verursachen kann. Die zusätzliche Installation von Xwayland wird empfohlen.

    **Installation aus dem Quellcode in einer virtuellen Umgebung:**

    Installieren Sie zunächst die für Ihr System benötigten Programme:

    - **Debian-basierte Systeme:** Installieren Sie pip zum Herunterladen zusätzlicher Python-Module mit `sudo apt install python3-pip`. Für Audio/Video installieren Sie VLC von dessen Website oder mit `sudo apt install vlc`. Bei der Desktopumgebung **Xfce** kann zusätzlich `sudo apt install libxcb-cursor0` erforderlich sein.
    - **Fedora:** Die Nutzung von VLC aus Python führt zu Abstürzen, für die bisher keine Lösung gefunden wurde. Audio/Video kann deshalb unter Fedora nicht innerhalb eines QualCoder-Projekts verwendet werden.
    - **Arch/Manjaro Linux:** Installieren Sie VLC bei Bedarf mit `sudo pacman -S vlc` und Python, pip sowie virtualenv mit `sudo pacman -S python python-pip python-virtualenv`.

    1. Laden Sie QualCoder herunter und entpacken Sie den Ordner.
    2. Wechseln Sie mit `cd` in diesen Ordner, beispielsweise `~/Downloads/QualCoder-4.0`.
    3. Sie können die folgenden Schritte über das Shellskript ausführen. Machen Sie es zunächst per Rechtsklick unter **Eigenschaften** ausführbar und starten Sie es mit:

        ```
        ./run_from_source_Linux.sh
        ```

        Alternativ erstellen Sie die virtuelle Umgebung `env` und installieren die Module manuell. Dies kann einige Zeit dauern:

        ```bash
        python3 -m venv env
        source env/bin/activate
        pip install --upgrade pip
        pip install -r requirements.txt
        ```

    4. Wechseln Sie in den Unterordner `src` und starten Sie QualCoder:

        ```bash
        cd src
        python3 -m qualcoder
        ```

    5. Verlassen Sie nach der Arbeit die virtuelle Umgebung mit `deactivate`.

    **Bei späteren Starts** wechseln Sie in den QualCoder-Ordner und führen aus:

    ```bash
    source env/bin/activate
    cd src
    python3 -m qualcoder
    ```

    Mit `deactivate` verlassen Sie die Umgebung wieder.

    Sie können auch eine `.desktop`-Datei als Programmstarter erstellen. Verwenden Sie darin folgenden Startbefehl und passen Sie den Pfad sowie die Python-Version an Ihre Installation an:

    ```bash
    bash -c 'cd ~/.local/share/qualcoder/src/ && ~/.local/share/qualcoder/env/bin/python3.12 -m qualcoder'
    ```
