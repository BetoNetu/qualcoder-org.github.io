# Literaturangaben

Öffnen Sie **Verwalten > Referenzen**, um ein Literaturverzeichnis zu importieren. Es muss als reine Textdatei im RIS- oder NBIB-Format vorliegen; mögliche Dateiendungen sind `.txt`, `.ris` und `.nbib`. Auch ein Import aus Zotero 7 ist möglich. Starten Sie dazu zunächst Zotero und aktivieren Sie in dessen Einstellungen die lokale API, damit QualCoder mit Zotero kommunizieren kann. Zugehörige PDF- oder EPUB-Dateien können ebenfalls importiert werden.

![Literaturangaben verwalten](/images/gh-c750c125-1214-466c-9d1f-c549c3a1ad15.png)

Klicken Sie auf die Importschaltfläche und wählen Sie die Literaturdatei. Das Beispiel verwendet `Examples/bibliography.ris`. Sie können alle, nur neue oder bestimmte Literaturangaben importieren. Vorhandene Anhänge, beispielsweise beim Import aus Zotero, lassen sich ebenfalls übernehmen.

![Literaturangaben für den Import auswählen](/images/650842457-6a209439-d45c-4e13-8138-5c4dae03e8bd.png)

Sie können Literaturangaben mit Dateien verknüpfen, Verknüpfungen aufheben, Angaben manuell bearbeiten und löschen.

Unter **Dateien verwalten** erscheinen vier zusätzliche Attributspalten: `Ref_Authors`, `Ref_Title`, `Ref_Type` und `Ref_Year`.

![Literaturattribute in der Dateiverwaltung](/images/3d85d09f-926c-46df-87cb-867ad8dce4c1.png)

Bei verknüpften Dateien enthalten diese Spalten die entsprechenden Angaben. Literaturangaben können auch in Analysen angezeigt werden, beispielsweise unter **Analyse > Code-Retrieval**.

Mit der Exportschaltfläche exportieren Sie alle Literaturangaben im RIS-Format.
