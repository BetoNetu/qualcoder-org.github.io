# Code Organisator

Mit diesem Werkzeug ändern Sie die Struktur des Codebaums.

Beim ersten Öffnen werden Sie aufgefordert, das Projekt zu sichern, bevor Sie Änderungen vornehmen oder anwenden. Die Änderungen lassen sich nicht rückgängig machen.

![Codes organisieren](/images/ae81b366-54e8-457f-9afe-abb7f76d2a41.png)

Über die Schaltfläche ganz links wählen Sie alle Zweige des Codebaums oder einen bestimmten Zweig aus.

![Zweig auswählen](/images/57b82319-1145-4872-a6c7-63cbc807b370.png)

Alle untergeordneten Kategorien und Codes Ihrer Auswahl werden angezeigt.

![Ausgewählte Codes und Kategorien](/images/303ddd26-605c-4963-9db4-ba7c50c40250.png)

**Codes:** Das Kontextmenü erlaubt, einen Code aus einer Kategorie zu entfernen, in eine andere Kategorie zu verschieben, mit einem anderen Code zusammenzuführen oder umzubenennen. Sie können außerdem das Memo anzeigen und bearbeiten, codierte Medien ansehen und das Memo unter dem Codenamen einblenden.

**Kategorien:** Über eine Schaltfläche oben legen Sie eine neue Kategorie an. Im Kontextmenü können Sie Kategorien zusammenführen, unter eine andere Kategorie verschieben oder aus ihrer übergeordneten Kategorie herauslösen. Außerdem können Sie sie umbenennen, Memos anzeigen und bearbeiten oder ein Memo unter dem Kategorienamen einblenden.

![Memo unter dem Kategorienamen](/images/92fee31b-1b70-4bdf-bb15-51b0485e4739.png)

Eine Schaltfläche exportiert die Darstellung als PNG-Datei.

Erst mit **Anwenden** werden die Änderungen in den Codebaum übernommen. Ohne diese Bestätigung bleibt die Projektstruktur unverändert.
