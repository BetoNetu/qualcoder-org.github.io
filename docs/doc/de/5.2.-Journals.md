# Notizbücher

Halten Sie beim Codieren Ihre Gedanken in Notizbüchern fest und entwickeln Sie daraus Ideen und Themen. Sie können einzelne Notizbücher exportieren oder die Texte aller Notizbücher in einer Datei zusammenfassen. Notizbücher können gelöscht und mit Attributen versehen werden.

![Notizbücher](/images/gh-ade4a42b-a40e-462e-b93f-607c6fb23365.png)

Die Textsuche unterstützt reguläre Ausdrücke für flexible Suchmuster:

- `.` steht für ein beliebiges Zeichen; `.ears` findet beispielsweise `bears` und `years`.
- `?` nach einem Zeichen macht dieses optional; `bears?` findet `bear` und `bears`.
- `*` erlaubt null oder mehr Wiederholungen des vorangehenden Zeichens.
- `\.` sucht einen Punkt, `\?` ein Fragezeichen und `\n` einen Zeilenumbruch.

!!! tip
    Weitere Beispiele bietet diese [Regex-Kurzübersicht](https://www.rexegg.com/regex-quickstart.html).

Sie können Notizbücher nach Name oder Datum sortieren und Attribute ergänzen. Im Kontextmenü können Sie die angezeigten Zeilen nach Namen, Coder:in oder Attributwerten filtern.

Das Notizbuchfenster lässt sich unabhängig vom Hauptfenster bewegen, sodass Sie während des Codierens oder der Berichtserstellung Notizen eingeben können.

## Text mit Markdown hervorheben {#highlight-journal-text-using-markdown}

Einige Markdown-Auszeichnungen werden unterstützt: Ein bis drei Rautenzeichen am Zeilenanfang kennzeichnen Überschriften. Ein Sternchenpaar um Text erzeugt Kursivschrift, zwei Sternchen auf jeder Seite erzeugen Fettschrift.

URLs werden erkannt und können über das Kontextmenü geöffnet werden.
