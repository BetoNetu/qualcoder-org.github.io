# SQLite-Datenstruktur

Diese Beschreibung der Datenstruktur v8 soll beim Erstellen von SQL-Abfragen helfen. Sie beschreibt die von QualCoder 3.2 verwendete Struktur. Ältere Datenbanken werden beim Öffnen an das entsprechende Format angepasst. Die folgende Übersicht entspricht dem Stand der englischen Dokumentation.

Die Tabellen sind zunächst alphabetisch aufgeführt. Tabellen- und Feldnamen bleiben unverändert. Die Datentypen `integer`, `real` und `text` bezeichnen Ganzzahlen, Fließkommazahlen und Text. `NULL` steht für einen nicht gesetzten Wert.

## Tabelle: source {#table-source}

| Feld | Typ | Bedeutung |
| --- | --- | --- |
| `id` | integer | Eindeutige, automatisch vergebene Nummer |
| `name` | text | Dateiname mit Endung zur Erkennung von Text, Bild oder Audio/Video; das Suffix `.transcribed` kennzeichnet in dieser Struktur die Zuordnung zur passenden Audio/Video-Datei |
| `fulltext` | text | Vollständiger Text in UTF-8; bei Bildern und Audio/Video `NULL` |
| `memo` | text | Memo |
| `owner` | text | Coder:in, die den Eintrag erstellt hat |
| `date` | text | Erstellungsdatum und -zeit im Format `yyyy-mm-dd hh:mm:ss` |
| `mediapath` | text | Medienpfad; Formate siehe unten |
| `av_text_id` | integer | Verknüpfung einer Audio/Video-Datei mit ihrem Texttranskript |

Ein leerer `mediapath` kennzeichnet einen intern gespeicherten Text. Bei einem Pfad mit `docs:` wird auf ein externes Textdokument verwiesen; der Text wird dennoch zur Bearbeitung in `fulltext` gespeichert.

Pfade mit `/images/`, `/audio/` oder `/video/` kennzeichnen Dateien im Projektordner. Präfixe `images:`, `audio:` und `video:` kennzeichnen dagegen externe Verknüpfungen mit vollständigem Dateipfad.
