# Kategorien und Codes

Kategorien organisieren Codes hierarchisch in einem Codebaum. Sie können Codes in Kategorien und Kategorien in übergeordnete Kategorien verschieben oder aus ihrer bisherigen Position herauslösen. Seit Version 4.0 kann ein Code auch Untercodes haben. Der Code darüber ist der übergeordnete Code. Zum Zusammenführen ziehen Sie einen Code auf einen anderen Code oder eine Kategorie auf eine andere Kategorie. Im Kontextmenü können Sie Codes und Kategorien umbenennen sowie die Codefarbe ändern.

Codes und Kategorien können Memos erhalten. Darin sind auch Sonderzeichen möglich, etwa die auf [dieser Seite gezeigten Symbole](https://www.alt-codes.net/). Die dortige Anleitung erläutert die Eingabe: Aktivieren Sie auf dem Laptop den Ziffernblock, halten Sie **Alt** gedrückt und geben Sie die Nummer über den Ziffernblock ein.

!!! note
    Ein Code kann nicht mehreren Kategorien zugeordnet werden. Diese häufig gewünschte Funktion würde statt des Codebaums eine [Graphstruktur](https://www.baeldung.com/cs/tree-vs-graph-data-structure) erfordern und die Umsetzung erheblich verkomplizieren. Sie können stattdessen ähnlich benannte Codes in verschiedenen Kategorien verwenden.

## Weniger Codes anzeigen {#reducing-the-amount-of-codes-displayed-in-the-codes-tree}

Im Kontextmenü des Codebaums der Arbeitsbereiche zum Codieren von Text, Audio/Video oder Bildern können Sie Codes nach Namen filtern. Alternativ drücken Sie **F9**, wenn der Codebaum den Fokus hat. Geben Sie einen Text ein, um nur Codes anzuzeigen, deren Name diesen enthält. Ein leeres Suchfeld und **OK** zeigen wieder alle Codes.

Sie können auch Codes nach Farbe filtern; dafür dient **F10**, wenn der Codebaum den Fokus hat.

Die Schaltfläche mit dem Suchsymbol unter dem Codebaum springt zum ersten Code, dessen Name den eingegebenen Text enthält.

## Kontextmenü des Codebaums {#codes-tree-menu-options}

Ein Rechtsklick auf einen Code im linken Codebaum öffnet Optionen zur Bearbeitung von Codes und Kategorien sowie zum Filtern und Sortieren.

![Kontextmenü des Codebaums](/images/4adaa97e-da9c-45bf-88f3-8e0110edf638.png)

### Codierte Dateien anzeigen {#show-coded-files}

Diese Option zeigt alle Stellen, die mit dem ausgewählten Code codiert wurden. Ein Klick auf ein Segment öffnet es im ursprünglichen Kontext.

Über das Kontextmenü der farbigen Überschrift können Sie weitere Codes hinzufügen, die Codierung entfernen oder alle angezeigten codierten Segmente als Textdatei exportieren.

![Codierte Dateien anzeigen](/images/7f0d079d-c0a8-4966-87bd-a6723f541d8d.png)

Mit **F11** sortieren Sie den Codebaum aufsteigend, mit **F12** absteigend. Der Codebaum muss dabei den Fokus haben.

## Barrierefreiheit und Codefarben {#accessibility-and-code-colours}

Im Menü **Codierung** finden Sie **Farbschema**. Damit weisen Sie mehreren ausgewählten Codes eine Farbpalette zu, statt Zufallsfarben zu verwenden oder jede Farbe einzeln zu ändern.

Sie können dort auch simulieren, wie die Codefarben für Menschen mit Rotsehschwäche, Rotblindheit, Grünsehschwäche oder Grünblindheit erscheinen.
