# Weitere Informationen und Lizenzen

QualCoder wird derzeit unter Windows 11 entwickelt. Die Software ist in Python 3 geschrieben und verwendet Qt6 für die grafische Oberfläche.

Nach Version 4.0 soll unter anderem die Benutzeroberfläche überarbeitet werden, um sie moderner und ansprechender zu gestalten. Außerdem soll zusätzliche Dokumentation zu Governance und organisatorischen Rahmenbedingungen entstehen, die den Einsatz in großen Institutionen unterstützt.

## Verwendete Betriebssysteme

QualCoder wird unter Windows 11, macOS, Ubuntu 24, Lubuntu, Fedora, Linux Mint, Arch Linux, NixOS und ZorinOS eingesetzt.

- Unter Fedora führt die Nutzung von Audio/Video zu Abstürzen.
- Unter Debian mit GNOME kann die Kacheloption die Fenstergröße von QualCoder verkleinern. Deaktivieren Sie in diesem Fall die Fensterkachelung in den GNOME-Einstellungen.

## Datenstrukturen

**Der QDA-Projektordner** enthält Ordner für importierte Dokumente und die SQLite-Datenbank mit den Codierungsdaten. Bei aktivierter KI gibt es zusätzlich den Ordner `ai_data` mit einer SQLite-Datenbank für den Chatverlauf und einem Vektorspeicher. Dieser enthält numerische Darstellungen von Wörtern, Wortgruppen und Sätzen, die für die KI verwendet werden.

**Der Arbeitsordner `.qualcoder`** liegt in Ihrem persönlichen Ordner. QualCoder legt dort `QualCoder.log` und Konfigurationsdateien an. Legen Sie darin keine sonstigen Dateien ab; er dient der Anwendung als Arbeitsbereich für Einstellungen und gespeicherte Zustände. **Der Ordner `.qualcoder_ai`** im persönlichen Ordner enthält die KI-Konfiguration.
