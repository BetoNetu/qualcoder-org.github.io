# Importações de _Survey_

Abra a página **Gerenciar** > **Arquivos** e pressione o botão **Importar _survey_**.

![image](/images/gh-4b49aacf-fd58-4fe1-a860-a037001e3a2f.png)

Um survey pode ser importado de um arquivo CSV (valores separados por vírgulas) ou de um arquivo Microsoft Excel (xlsx). **A primeira linha deve conter os cabeçalhos para atributos e para os dados de texto livre. A primeira coluna deve conter os identificadores únicos para cada entrevistado.**

Existem alguns surveys de exemplo na pasta `Exemplos`. Estes serão utilizados numa análise das importações de surveys:

Acima está a pasta de exemplos, mostrando vários arquivos de _survey_.

Acima estão os dados em `survey456.csv`.

## Importando o arquivo `survey456.csv`

Pressione o botão importar survey e selecione o arquivo na pasta Exemplos.

![image](/images/gh-c777dc45-5aec-4c2e-a705-8ef8abc7418a.png)

O assistente de survey lê o arquivo CSV e mostra os nomes das colunas à esquerda.

![image](/images/gh-a17388a6-db2f-423b-8b6d-69f8c59d172a.png)

O identificador do participante, denominado Caso neste _survey_, pode ser atribuído à seção Casos/Participantes. As colunas de dados Idade, Gênero e Interesses podem ser designadas aos atributos. A coluna texto livre pode ser atribuída aos Textos Qualitativos. Neste exemplo, atribuiremos os atributos aos arquivos, e não iremos autocodificar o texto qualitativo com o nome da coluna '_freetext_'. O QualCoder determinará se as colunas de atributos são Numéricas ou Caracter. Para colunas numéricas, cada célula deve conter um número ou estar vazia, caso contrário os itens serão predefinidos como Caracter.

![image](/images/gh-44838a3e-5d0b-4aac-aef5-ae6b6b6c4758.png)

Pressione OK para efetivar a importação.

![image](/images/gh-e806f734-8b04-4487-bc0d-7a3fe3c0eca6.png)

Os atributos foram atribuídos a cada arquivo de texto. A abertura do arquivo de texto mostra os detalhes do texto. O texto é sublinhado em verde, isto significa que todo o texto é atribuído a um caso correspondente. Na image abaixo, Survey ID4.txt foi atribuído a um caso recém-criado chamado ID4.

![image](/images/gh-5cc455fe-a401-47cc-ba1f-08d0c752ba8b.png)

Na Gerenciar > Tela de casos é mostrado assim, com um arquivo de texto atribuído por caso:

![image](/images/gh-a35b341a-40e6-4d38-9647-179f6bc25d5e.png)

### Adicionando mais dados

Usando o botão de importação do survey, selecione e importe o arquivo `survey789.xls`. Deixe as caixas de seleção desmarcadas.

![image](/images/gh-03a07b75-d7bf-496d-952c-cb397ebab8f7.png)

Este tem duas colunas qualitativas diferentes:

![image](/images/gh-f48d1b04-26a9-45eb-a88a-f86ffb8716f4.png)

Pressione OK.

![image](/images/gh-79b7a8e5-0bf6-4a80-9acf-ace6965acca7.png)

Os novos arquivos qualitativos foram adicionados, e os atributos do arquivo agora são estendidos com as três novas respostas do survey. A diferença aqui é que os novos arquivos tinham diferentes componentes qualitativos. Ambas as colunas de resposta qualitativa foram reunidas em um arquivo de texto para cada caso.
