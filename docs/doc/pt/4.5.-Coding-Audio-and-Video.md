# Codificar áudio e vídeo

Ao codificar vídeo, duas telas são exibidas, como mostrado abaixo. Uma tela contem o vídeo que esta sendo reproduzido. A outra tela principal tem os controles e um botão para iniciar e terminar um trecho codificado. A janela de controles mostra os códigos no painel inferior esquerdo e o texto do arquivo `.transcribed` é mostrado no painel inferior direito. Ao codificar áudio, somente a tela principal é mostrada.

O texto de transcrição também pode ser codificado e anotado nesta janela. Clicar com o botão direito do mouse em uma hora na transcrição lhe dará uma opção de menu para ir para essa seção do vídeo. Se um vídeo tem várias faixas de áudio, você pode alterar a faixa de áudio também. Verificando a caixa de seleção rolagem permite que a transcrição role no tempo com o vídeo, com base em datas detectadas; no entanto, você precisa desmarcar a rolagem para ser capaz de codificar a transcrição.

## Atalhos de teclado {#keyboard-shortcuts}

* Ctrl+R Rebobina 5 segundos
* Alt+R ou Alt+Menos Rebobina 30 segundos
* Alt+F ou Alt+Mais/Alt+Igual Avança 30 segundos
* Ctrl+P ou Ctrl+D para/inicia (_play_/_pause_). Ao retomar o áudio/vídeo rebobina um segundo.
* Ctrl+S iniciará/fim A/V criação de segmento.
* Ctrl+Shift+< reduz a velocidade da mídia até o mínimo de 0,1x (ou 10% da original)
* Ctrl+Shift+> aumenta velocidade da mídia até o até duas vezes (2x).
* Ctrl+Z Restaura o último código não marcado.

(Estas opções também estão disponíveis através dos ícones na barra de ferramentas)

Quando a área de texto está selecionada:

* Pressione A para anotar o texto selecionado
* Pressione L para 'Mostrar códigos como', para mostrar uma lista na árvore de códigos.
* Pressione M para memorando de um código. (Deve clicar sobre um segmento de texto codificado)
* Pressione O para alternar pelos códigos sobrepostos _in situ_. (Deve clicar sobre um trecho com códigos sobrepostos - denotado com um _overline_).
* Pressione Q para codificação rápida, usando o código mais recente. (Deve ter um trecho de texto selecionado)
* Pressione R para selecionar códigos recentes. (Deve ter um trecho de texto selecionado)

## Segmentos de vídeo e de áudio {#audio-video-segments}

Uma vez que um segmento é criado usando o botão  Iniciar segmento/Parar segmento, ele pode ser atribuído a um código clicando com o botão direito do _mouse_ no código relevante e atribuindo o segmento.

Faixas de codificação para os segmentos codificados são mostradas na área inferior. Passar o mouse sobre cada faixa mostra o nome de código, tempo do segmento, e qualquer memorando anexado a esse segmento codificado. Clicar com o botão direito em uma faixa de segmento codificado mostra um menu que pode ser usado para editar o memorando, marcar como um segmento importante ou excluir o segmento codificado.

O texto transcrito também pode ser codificado e anotado nesta janela. No entanto, quando a caixa de verificação de rolar transcrição é marcada, isso não pode ser realizado. Reproduzir o vídeo quando este estiver marcado irá rolar a transcrição usando as marcações de tempo sincornizadas com o vídeo.

## Texto e segmentos codificados como importantes {#important-coded-text-and-segments}

Textos codificados importantes, como exemplos para um relatório, podem ser sinalizados como Importante usando o menu com o botão direito do _mouse_ quando no texto codificado e selecionando Importante. Da mesma forma, trechos de código podem ser sinalizados Importante. No topo da tela está um botão com um símbolo de estrela. Isto alterna entre mostrar todos os trechos de texto codificados e trechos de texto codificadados marcados como importantes.

**Ligando texto a segmentos codificados**

Selecione o texto (pode ser codificado ou preferencialmente não codificado), então atribua-o a um segmento. Primeiro, selecione o texto. Em seguida, clique com o botão direito na faixa de segmento para abrir o menu. Escolha o Vincular texto ao segmento, para atribuir o texto.

## Modificar as posições do código na área de texto {#modifying-code-positions-in-the-text-area}

Quando na área de texto, clique em um código com o _mouse_ (Nota: o código não deve se sobrepor a outro código nessa mesma posição). Pressione as seguintes combinações de teclas para estender ou encolher o segmento de texto codificado.

* Shift+seta esquerda: Extende o texto codificado para a esquerda
* Shift+seta direita: Extende o texto codificado para a direita
* Alt+seta esquerda: Encolhe o texto codificado do lado direito para a esquerda
* Alt+seta direita: Encolhe o texto codificado do lado esquerdo para a direita

Você também pode clicar com o botão direito em um código e selecionar mudar a posição inicial ou mudar a posição final usando as seleções deslizáveis.

Você também pode exportar uma captura de tela. A imagem será salva como `Frame_yyyymmdd_hh_mm_ss.jpg`. Você pode salvar essa imagem para codificação de imagem dentro do projeto.

## Botões de conveniência abaixo da lista de arquivos {#convenience-buttons-underneath-the-files-list}

* Carregar o próximo arquivo
* Carregar o arquivo com a última codificação
* Abrir o memorando do arquivo selecionado
* Usar uma função de filtro para mostrar apenas os arquivos que atendem a determinados critérios. Estes podem ser de atributos de arquivo ou se os arquivos estão associados a certos casos.

## Problemas de áudio e vídeo em alguns sistemas operacionais {#audio-and-video-problems-on-some-operating-systems}

O Fedora não funciona com o áudio e vídeo.
