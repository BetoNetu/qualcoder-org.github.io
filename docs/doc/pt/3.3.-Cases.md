# Gerenciando casos

Casos são úteis para coligir vários arquivos para uma determinada circunstância ou pessoa. Os casos podem ter atributos como idade e gênero para os participantes. Você pode adicionar um memorando de notas a cada caso e renomear um caso clicando duas vezes em um nome de caso. Nem todos os projetos precisam de casos, por exemplo, um projeto de entrevistas individuais seria carregado como transcrições de texto individuais, e esses arquivos podem receber atribuídos atributos em  Gerenciar Arquivol, como o papel de uma pessoa, idade, etc.

Há uma tabela que lista os casos e seus atributos. Nela, o número de arquivos associados a um caso é mostrado. Clique na célula Arquivos na tabela para adicionar ou alterar arquivos associados a esse caso. Isto mostrará a janela do Gerenciador de Arquivos, descrita abaixo.

Quando uma _survey_ é importada, cada linha da _survey_ pode ser atribuída a um caso. O nome do caso é o identificador único na primeira coluna da planilha csv ou Excel. Grandes _surveys_ (por exemplo, 1000 ou mais linhas) podem demorar muito para importar, pois os casos levam algum tempo para criar.

![image](/images/a2076cfb-da5e-486f-a443-6ef6a070fc9a.png)

## Ocultar e mostrar linhas e colunas {#hiding-and-showing-rows-and-columns}

Oculte colunas com o botão direito do _mouse_ no cabeçalho da tabela para as opções para ocultar essa coluna ou para ocultar colunas começando com texto específico. Ou para mostrar colunas começando com um valor de texto. Oculte linhas pelo menu com o botão direito do _mouse_ e selecione um valor de texto que seja igual ou 'é como' algum texto escolhido. Clique com o botão direito para ordenar pelo nome do caso ou pelo valor do atributo, ordem ascendente ou ordem descendente.

!!! example "Exemplo prático"
    Adicione os três alunos (ou casos) clicando no ícone Adicionar caso. Nomeie cada estudante: ID1, ID2 e ID3.

## Gerenciador de arquivos de casos {#case-file-manager}

Agora, adicione o arquivo de cada estudante a cada caso de estudante. Clique na célula na coluna Arquivos para o caso ID3, por exemplo. Isto abre a janela do _gerenciador de arquivos de casos_. Você pode também, clicar no ícone de documentos, o que também abrirá o gerenciador de arquivos de caso.

![imagem](/images/a322b68d-8f3a-49ec-ab9f-39bd67253d3e.png)

No gerenciador de arquivos de caso, clique em um caso, digamos ID3, em seguida, clique no botão Adicionar arquivos selecionados para o caso. Selecione um ou mais arquivos na lista de arquivos. Adicione os arquivos à caixa. Por exemplo, adicione `miguel-henriques.jpg` ao ID3. Você pode remover arquivos e visualizar os arquivos associados ao caso. Você verá que o texto do arquivo será sublinhado em vermelho, o que indica que este texto está associado a este caso.

Você também pode selecionar um caso, destacar manualmente partes de texto dentro de um documento de texto maior, e clicar com o botão direito para marcar – ou atribuir – o texto para o caso selecionado.

## Importando casos e atributos de caso {#importing-cases-and-case-attributes}

Você pode importar atributos de um arquivo CSV ou XLSX usando este botão:
![imagem](/images/0b9d8a34-33ff-4591-ae6d-c6f43bfb9625.png)

A primeira linha deve conter os cabeçalhos dos atributos. A primeira coluna deve conter os nomes dos casos correspondentes (para este exemplo: ID1, ID2, ID3). Note que os nomes são sensíveis à capitulação do texto (caixa_baixa ≠ CAIXA_ALTA). Abra o arquivo `cases.csv` na pasta `Examples` para ver como ele é definido.

Para este exemplo – exclua todos os casos mostrados. Em seguida, importe os atributos do arquivo `cases.csv` por meio da janela Importar Atributos. Você precisará novamente ligar os arquivos e o texto do arquivo a cada caso.
