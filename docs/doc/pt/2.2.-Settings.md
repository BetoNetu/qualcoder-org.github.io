# Configurações

A janela de configurações permite que você altere vários recursos, incluindo idioma, nome do codificador, tipo de fonte e tamanho da fonte, bem como as opções da integração de IA.

![image](/images/baec9b31-e0bd-4607-85c2-65e141f040d6.png)

### Nome do codificador {#coder-name}

Vários codificadores podem codificar e anotar o mesmo texto. O seu nome de codificador atual é mostrado no topo da janela de configuração.

![image](/images/gh-04951ae2-c5ab-41e7-854f-dad9819183f4.png)

Este nome será usado para identificar suas contribuições para o projeto. Clique no botão "Alterar" para alterar sua identidade ou para criar, renomear ou mesclar outros codificadores no projeto atual. Leia [Trabalhando em equipe](2.4.-Working-in-a-Team#important-considerations-regarding-coder-names) para mais informações.

### Configurações gerais {#general-settings}

O idioma padrão do QualCoder é o inglês. Francês, alemão e espanhol são idiomas alternativos regularmente atualizados. Outros idiomas não foram cuidadosamente revisados para precisão. Para outros idiomas mantidos pela comunidade, [baixe o arquivo relevante.zip](/community) e o coloque na pastsa `.qualcoder/i18n`, em seguida, selecione seu idioma nas configurações.

Marcar a caixa Mostrar IDs exibe os IDs numéricos para arquivos, de códigos, casos e muito mais. Tais IDs podem ser úteis ao escrever consultas SQL.

Há poucas opções para alterar a aparência geral do QualCoder.

Para transcrever áudio e vídeo, o formato de tempo e o tipo de parenteses (parenteses ou colchetes) podem ser selecionados.

### _backups_ {#backups}

O _backup_ do projeto pode ser configurado para _backup_ automático a cada hora, ou sem _backup_. O QualCoder mantem os _backups_ mais recentes com data e hora. O nome de _backup_ é: _nomedoprojeto_BKP_yyyymmdd_hh.qda_ onde _hh_ é 24 horas. Isso também significa que vários _backups_ não são feitos dentro de uma hora. Assim, um novo _backup_ não substitui outro _backup_ criado na mesma hora. Um número limitado de _backups_ são mantidos, **_backups_ mais antigos são excluídos**. As configurações permitem que você escolha entre 1 e 10 _backups_.

Recomendamos que você faça um _backup_ antes de fazer qualquer alteração substancial, como reorganizar códigos e categorias, fundir projetos ou mesclar códigos. O QualCoder realiza _backups_ por hora (mantendo até os cinco mais recentes) se os _backups_ estiverem definidos nas configurações.

Renomeie ou mova para outro local os _backups_ específicos que você precisa manter. Quando os _backups_ são definidos, uma opção adicional é escolher fazer _backup_ dos arquivos de áudio/vídeo. Para a completude dos _backups_ é recomendável fazer _backup_ de áudio e vídeo, no entanto, isso pode tornar a abertura do software mais lenta se você tiver muitos arquivos grandes. Como alternativa, você pode criar _links_ para arquivos de áudio/vídeo grandes em vez de importá-los na pasta do projeto. O diretório padrão do projeto é o local que muitas operações têm como padrão para exportar ou importar arquivos.

Em sua pasta pessoal, o QualCoder criará uma pasta `.qualcoder` com um arquivo `QualCoder.log` para registrar eventos e um arquivo `config.ini` que conterá muitas configurações, como o nome do codificador atual, fontes preferenciais, idioma e um diretório de trabalho preferido. Não armaneze quaisquer dados ou projetos dentro da pasta `.qualcoder`. O único arquivo que você deve colocar aqui é o `stopwords.txt`, somente se você precisar aplicar um conjunto de exlusão de palavras para as funções de nuvem de palavras e contagem de palavras. Esta pasta é apenas para o QualCoder usar quando ele está em execução.
