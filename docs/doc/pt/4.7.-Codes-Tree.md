#  Categorias e códigos

As categorias são utilizadas para organizar códigos. As categorias são organizadas hierarquicamente em uma estrutura de árvore. Você pode mover códigos para categorias e mover categorias para categorias maiores. Você pode mover categorias e códigos para fora de sua posição atual. Um código pode ter sub-códigos (novidade da versão 4.0). Códigos e categorias podem ser mesclados através da introdução de um código em um código ou categoria em uma categoria. Clique com o botão direito em uma categoria ou código para renomear. Clique com o botão direito num código para alterar a cor.

Categorias e códigos podem ser atribuídos memorandos. Os memorandos podem conter símbolos como os [mostrados aqui](https://www.alt-codes.net//). Veja o tutorial para inseri-los - Laptop com o Num Lock ligado, segure a tecla Alt para baixo e digite o número usando o teclado número à direita.

!!! note
    A capacidade de atribuir um único código a várias categorias é uma característica frequentemente solicitada. No entanto, decidimos não implementar essa funcionalidade, pois seria excessivamente complicado. Isso é devido ao uso da estrutura de uma árvore pelo QualCoder, enquanto o recurso solicitado requer [estrutura de dados do gráfico](https://www.baeldung.com/cs/tree-vs-graph-data-structure). Como alternativa, você pode usar códigos com nomes semelhantes em suas diferentes categorias.

## Redução da quantidade de códigos exibidos na árvore de códigos {#reducing-the-amount-of-codes-displayed-in-the-codes-tree}

Para reduzir o número de códigos mostrados na árvore de códigos. Nas janelas de codificação (codificar, codificar, a/v ou codificar imagem), clique com o botão direito na árvore de códigos e selecione _Mostrar códigos como_ no menu, ou quando a árvore de códigos está focada pressione F9. Em seguida, digite texto na caixa de texto. Isto só mostrará códigos que contenham esse texto. Para mostrar todos os códigos novamente, basta digitar nada (ou apagar o texto inserido) na caixa de texto e pressione OK para mostrar todos os códigos.

Uma segunda opção é Mostrar códigos coloridos . Pressione a tecla F10 quando a árvore de códigos está focada.

Outro botão sob a árvore de códigos - com um ícone de pesquisa - irá procurar, ao clicá-lo, o primeiro código que contém o texto correspondente que você inserir.

## Opções do menu da árvore de códigos {#codes-tree-menu-options}

Na árvore de códigos à esquerda, clicando com o botão direito em um código abre um menu de contexto para várias opções. Sub-menus incluem modificar um código ou categoria, filtragem e ordenação.

![imagem](/images/4adaa97e-da9c-45bf-88f3-8e0110edf638.png)

###  Mostrar os ficheiros codificados {#show-coded-files}

Uma opção é Mostrar arquivos codificados - isso mostra todos os lugares em que você tenha codificado com o código selecionado. Clicando em uma seção codificada em particular irá abrir esse código no contexto original para mais informações.

Com Mostrar arquivos codificados, você pode clicar com o botão direito na seção de cabeçalho colorido para mais opções, tais como adicionar mais códigos, remover o código e exportar todo o conjunto de segmentos codificados para um arquivo de texto.

![imagem](/images/7f0d079d-c0a8-4966-87bd-a6723f541d8d.png)

Ordene a árvore de códigos de modo ascendente (tecla F11 quando a árvore de códigos está focada), ou descendente (tecla F12 quando a árvore de códigos está focada).

## Acessibilidade e cores de código {#accessibility-and-code-colours}

No menu de codificação existe uma opção chamada **paleta de cores**.

Você pode aplicar uma gama de cores a uma gama de códigos selecionados, em vez de confiar nas cores geradas aleatoriamente ou mudar uma cor de cada vez para cada código. Nesta área você também pode ver como as cores dos códigos podem aparecer para alguém que possui diferentes tipos de daltonismo: vermelho-fraco, cego ao vermelho-cego, verde-fraco ou cego ao verde.
