# Codificar Texto

Selecione o texto do código no menu Coding. Uma vez que os segmentos de texto são codificados, passar o mouse sobre a codificação mostra o nome de código como uma dica. Clicando no segmento codificado também mostra o nome de código.

![image](/images/6f26284e-0802-4bd8-a75d-6b0e6562901c.png)

O texto codificado pode ser destacado através de um sublinhado, ou um estilo de marcação:

![image](/images/50bb8b05-73e9-41d8-9844-1ada6378d8a7.png)


![image](/images/750bb5f3-5c81-493a-a4ee-85a94874070b.png)

_Selecionar um arquivo_

Selecione um arquivo para codificação na lista de seleção no painel superior esquerdo. Abaixo estão botões que permitem que você acesse o próximo arquivo, para mover para o arquivo codificado mais recente e para ir para uma posição marcada como favoritos em um arquivo, para ver o memorando de arquivo e um botão Atributos que filtra os arquivos com base em seus atributos. Além disso, há um menu de opções com o botão direito do _mouse_, o qual inclui ordenação.

_Criar um código_

Crie um novo código clicando com o botão direito no painel inferior esquerdo da janela. Os códigos podem ser atribuídos uma cor clicando com o botão direito do _mouse_ no código e selecionando a opção de mudança de cor do código. Existe um botão na seção do cabeçalho com uma imagem de Paleta de tintas que irá definir todos os códigos recém-criados para a sua cor selecionada, em vez de atribuição de cores aleatórias.

Clique com o botão direito em um código para mais opções de um menu: adicionar um memorando a um código, excluir um código, renomear, adicionar um novo código e adicione uma nova categoria, mostraar códigos como (um determinado nome), mover um código ou categoria, adicionar uma categoria, ordenar.

_Codificar texto_

A maneira mais fácil de codificar texto, é selecionar algum texto, em seguida, clique com o botão esquerdo do mouse em um código na árvore de código. Alternativamente, selecione algum texto. Clique com o botão direito para abrir um menu e marcar o texto com opções como o código atual, códigos recentes, um novo código, código ir in vivo.

Passe o ponteiro do mouse sobre o texto codificado para ver informações do código e qualquer memorando. O texto codificado pode ser descodificado clicando no segmento de texto e pressionando o botão Desmarcar.

Segmentos de texto codificados podem ser memorizados - através do menu com o botão direito do mouse, pressionando 'M' ou clicando no botão 'notepad e lápis' mais à direita. O texto codificado e memorando é itálico.

Textos codificados importantes, como exemplos para um relatório, podem ser marcados  Importante  usando o menu com o botão direito do mouse quando no texto codificado e selecionando a opção Importante. O botão Star por baixo da árvore de códigos alterna entre mostrar todo o texto codificado e texto codificado marcado como importante.

_Sobreposição de códigos_

Sobreposição de códigos pode ser difícil de ver claramente. As secções sobrepostas são sublinhadas. O cursor do rato irá mostrar texto codificado sobreposto. Você pode pressionar 'O' depois de clicar em uma seção sobreposta para percorrer os códigos nesse local.

## Anotações {#annotations}
Adicione uma anotação (um memorando para um segmento de texto) a uma seleção de texto. Estes são úteis para explicar siglas e jargão. O texto ficará arrojado para marcar a posição da anotação. Para reabrir uma anotação, selecione alguns dos textos em negrito e clique com o botão direito para obter a opção Anotar. Em alternativa, clique no bloco de notas mais à esquerda e no botão lápis, ou pressione a tecla 'A'. Para remover uma anotação, abra a anotação e apague todo o texto.

![image](/images/104526a8-1bba-4dae-8bcd-43d2ddc5f9c8.png)

## Codificação automática {#auto-code}

O canto superior direito da tela tem botões para a codificação automática de texto:
![botões de Codificação automática](/images/d689c833-505f-49e4-938c-e392d4a2cc14.png)


Você pode:

* Codificar automaticamente texto exato. Uma janela extra irá perguntar quais arquivos você deseja auto-codificar.

* Codificar automaticamente com base em um fragmento de texto. Uma janela extra irá perguntar quais arquivos você deseja auto-codificar.

* Codificar automaticamente o arquivo atual usando as marcas de texto inicial e final. Você pode usar ‘\n’ para um caractere final-de-linha. O texto da marca inicial está incluído na seção codificada.

* Desfazer a codificação automática anterior

* Uma caixa de seleção para ativar o Regex. Esta é uma função especial para aplicar uma codificação automática mais flexível com base em _wildcards_ e outras funções. Veja este [memorando](https://techearl.com/regex-cheat-sheet).

A codificação automática é sensível à capitulação do texto. Você também deve definir o fim de uma frase, há uma configuração padrão com um ponto final e espaço. \n pode ser usado também para denotar um caractere final-de-linha.

Para auto-codificar correspondências de texto exatas, várias seções de texto podem ser atribuídas pela codificação automática usando o símbolo de _pipe_ (barra vertical) '|'. Por exemplo, políticos podem ser atribuídos ao mesmo código ao mesmo tempo (para o texto de código automático exato corresponde apenas). Existe uma opção de desfazer a auto-codificação realizada recentemente. Embora se o projeto for fechado e reaberto, a opção desfazer será perdida.

O botão Codificar texto exato automaticamente e o botão  Codificar framgmento de texto automaticamente têm um menu com o botão direito do _mouse_ para mais opções. O padrão é codificar automaticamente todo o texto. Porém, existem opções para autocodificar apenas o primeiro texto correspondente ou o último texto correspondente no documento. Outra opção é aplicar a codificação automática somente se ele aparecer dentro de outro código (por exemplo, dentro de um texto de interlocutor codificado). Os botões codificar texto exato automaticamente codificar framgmento de texto automaticamente perguntam quais arquivos você quer codificar automaticamente.

Existe um botão de desfazer para remover as auto-codificações que foram aplicadas por último.

**Emoji's, emoticons em texto e auto-codificação**

 Os caracteres emoji podem contar como 1 caractere em uma _string_, mas ocupam 2 ou mais posições no editor visual, levando a cálculos incorretos. Aplicar a codificação automática significa que pode haver uma mudança de posições de caracteres ao aplicar a codificação automática ao texto.

 Exemplo da auto-codificação da palavra 'música', cada emoji é mostrado como 'um' caractere, mas nos bastidores são 2 caracteres. Isso pode resultar em uma mudança como se vê abaixo:

## Codificações de colunas automáticas {#auto-speaker-codings}

A função "Marcar Interlocutores" cria códigos para cada interlocutor em uma entrevista ou discussão em grupo, e atribui enunciados automaticamente. Isto permite mais relatórios focados, apenas olhando para certos oradores de cada vez. Você pode alcançar a função através do menu de contexto do arquivo ou do seguinte botão da barra de ferramentas:

![image](/images/645f0a43-4814-466e-a8a0-10758b910bb0.png)

- O nome do interlocutor deve estar no início de uma nova linha e ter menos de 64 caracteres. Os seguintes formatos são detectados: "Nome:", "{Nome}" ou "[Nome]"
- Você pode selecionar quais nomes você deseja incluir e até mesmo editar o rótulo:

![image](/images/67c14d0f-2c9a-4e99-8907-9c16a32b6285.png)

- Cada interlocutor terá seu próprio código na categoria especial "📌interlocutores" no fundo da árvore de código. As cores padrão são em escalas de cinza, para torná-las uma distração menor.
- No entanto, você ainda pode optar por ocultar esses códigos na janela de texto, para que eles não distraiam você em sua própria codificação analítica. Para fazer isso, clique no botão "..." ao lado do nome do codificador no canto superior-esquerdo da barra de ferramentas. No diálogo a seguir, selecione a entrada de "📌codificação do interlocutor" e defina a visibilidade para "oculto".
- A função "marcar interlocutors" também está disponível no espaço de trabalho "Gerenciar Arquivos".

Para ocultar o painel de controle superior, clique na área de texto e pressione a tecla 'H'. Para mostrar o painel superior, pressione 'H' novamente.

## Métodos de conveniência para carregar arquivos de texto no painel da lista de arquivos. {#convenience-methods-for-loading-text-files-in-the-files-list-pane}

Alguns projetos podem ter muitos arquivos de texto e a janela de visualização de arquivos pode apresentar muitos arquivos para serem abertos. Clique com o botão direito do _mouse_ nos arquivos no botão árvore de arquivos para ir para o próximo arquivo, ir para arquivo marcado como favorito ou ir para o arquivo com os códigos mais recentes:

* O próximo arquivo alfabeticamente,
* Selecione o arquivo que foi codificado mais recentemente,
* Ir para uma localização marcada num arquivo. Para criar um favorito, clique com o botão direito em algum texto ao codificar e selecione a opção favorito. O favorito funciona apenas para um projeto de cada vez, então se você abrir um projeto diferente, o favorito estará incorreto ou pode não funcionar.

## Modificando posições de código {#modifying-code-positions}

Clique com o botão direito em um código e selecione Redimensionar. As alças em cada extremidade do segmento codificado podem ser reposicionadas.

![image](/images/8b9e09f0-03e0-4ad1-8042-f7aa5ce12b31.png)

Alternativamente, clique em um código com o _mouse_ (Note que o código não deve ser sobreposto com outro código nessa posição). Pressione as seguintes combinações de teclas para estender ou encolher o trecho de texto codificado.

* Shift+seta esquerda Extende o texto codificado para a esquerda
* Shift+seta direita Extende o texto codificado para a direita
* Alt+seta esquerda encolhe texto codificado do lado direito para a esquerda
* Alt+seta direita encolhe texto codificado do lado esquerdo para a direita

É sempre melhor salvar uma cópia do projeto antes de editar o texto, para evitar a necessidade de editar posições de codificação, no caso de, depois de editar texto, as posições de codificação serem deslocadas incorretamente. As teclas abaixo podem ajudar a recuperar as posições corretas.

* Jogo da Velha/Símbolo de _hash_ (\#) Exibe a posição do caractere clicado.
* Cifrão ($) Move as posições do código, após a posição do caracter clicado. Pode ser necessário depois que o texto é editado (adicionado ou excluído) para mover segmentos de codificação subsequentes por um número de caracteres.

* B. Marque a localização atual no arquivo de texto atual. Shift+B para ir para o marcador.

* C. Na área de texto. Criar uma categoria.

* H. Ocultar e mostrar a seção superior dos controles na tela. Isso fornece uma área maior para ver o texto e para codificar.

* Ctrl+Z. Restaura o último código que não foi marcado.

## Procurar texto {#search-text}

O diálogo de codificação de texto contém uma função de busca por texto na área meio-superior, com as caixas de seleção para buscas sensíveis à capitulação e para pesquisar em todos os arquivos de texto. Quando na área de texto, selecionar algum texto e pressionar a tecla  's' preenche a caixa de texto de pesquisa e foca no botão de seta 'próximo' para buscar rapidamente através do documento o texto selecionado. A busca requer um mínimo de 3 caracteres por padrão. Clique com o botão direito para alterar o padrão para 5 caracteres, ou para pesquisar apenas após Enter ser pressionado. A caixa de seleção Sensível à Capitulação limita-se à pesquisa sensível à Capitulação. A caixa de seleção Todos os arquivos continuará a pesquisa em outros arquivos de texto.

A pesquisa usa funções de expressões regulares (Regex).

* O ponto final «.» é utilizado como _wildcard_, por exemplo, «.eio» corresponde a «feio» e «meio».
* ‘?’ depois de um caractere corresponde a sua aparição uma ou nenhuma vez, por exemplo, ‘ursos?’ combinará ‘urso’ e ‘ursos’
* ‘*’ após um caractere a sua aparição zero ou mais vezes.
* ‘\.’ irá corresponder ao ponto final, '\?' irá corresponder ao ponto de interrogação. '\n' irá corresponder ao símbolo de fim de linha. Isto [Folha de fraude do Regex](www.rexegg.com/regex-quickstart.html) pode ajudar.
* \b limite de palavra, '\bbound\b' irá procurar a palavra completa 'bound', mas não 'boundary'

## Movendo-se pelo texto para um código selecionado {#moving-through-the-text-for-one-selected-code}

Debaixo da árvore de códigos estão os botões: para frente, para trás e um botão de ícone de grade (para sair da função).

Selecione um código e, em seguida, clique nas setas para frente e para trás. Estes agora atravessam o documento de texto, mostrando o texto codificado para o código selecionado. Todos os outros textos codificados ficam oculto. Para restaurar e mostrar todos os códigos, clique no botão da grade agora colorida.

!!! note "Nota"
    Na versão 4.0, todo o arquivo de texto é mostrado. Nas versões anteriores, por exemplo, 3.8.2 havia uma opção para carregar um arquivo de texto em pedaços de 50.000 caracteres. Se você precisa carregar texto em blocos, então recomendamos que você use a  [versão anterior do QualCoder (3.8.2)](https://github.com/ccbogel/QualCoder/releases/tag/3.8.2). No entanto, note que o carregamento de texto em PDF mudou entre a 3.8.2 e a 4.0, o que pode causar imprecisão com as posições do segmento de codificação ao abrir um projeto mais novo (por exemplo, 4.0+) na versão mais antiga (3.8.2 ou anterior).

## Mostrar apenas texto codificado importante {#show-only-important-coded-text}

Sob a árvore de códigos está um botão com um símbolo de estrela. Este botão alterna entre mostrar todo o texto codificado e o texto codificado marcado como Importante.

## Edição de texto quando em codificação - Codificar Texto {#editing-text-when-in-coding-code-text}

O texto pode ser editado mesmo após o texto ser codificado ou anotado ou atribuído (total ou parcialmente) a um caso. Trechos do arquivo de texto ou arquivo áudio/vídeo transcrito terão trechos de texto sublinhados em verde (caso atribuído), amarelo (anotação) ou vermelho (codificado) - para todos os codificadores.

!!! note
    BOA PRÁTICA: Salve uma cópia do projeto antes de editar um arquivo de texto já codificado. Isto é apenas no caso de as posições das codificações serem reposicionadas incorretamente.

Ao entrar no modo de edição, todo o arquivo é carregado para edição. Outras funções como a árvore de códigos e lista de arquivos são desativadas.

Você pode selecionar texto que não está sublinhado e copiar/substituir sem problemas. Você pode clicar em uma posição (sem selecionar texto) para então digitar, excluir ou colar texto. Isto pode ser feito em locais de texto sublinhados (codificados, anotados, atribuídos a casos) ou não sublinhados (não codificados/anotados/atribuídos a casos). Você verá o deslocamento de sublinhados conforme se adiciona ou remove texto.

Existem algumas limitações: É melhor evitar selecionar seções de texto para excluir (ou digitar ou colar). Isso é particularmente um problema se alguma desses trechos tiver sido sublinhado (codificada, anotada, atribuída).Uma explicação possível é que as posições dos códigos/anotações subjacentes/case-atribuídos podem não corresponder corretamente como pretendido.

Se você fez uma alteração que você acha que afetou essas posições codificadas/anotadas/atribuídas de modo ruim, saia da janela de edição de texto. Em seguida, **antes de qualquer outra coisa ser feita** pressione o botão desfazer (seta para trás) ao lado do botão Editar texto.

![image](/images/d9496b21-a494-433f-84a5-cbac8419449f.png)

!!! note "Nota"
    Importante: As edições ocorrem dentro do texto armazenado no banco de dados. O arquivo de texto original NÃO é alterado.
