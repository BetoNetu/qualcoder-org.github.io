# Outras Informações e Licenças

Atualmente, o QualCoder é desenvolvido no Windows 11. O QualCoder é escrito em python 3 usando o Qt6 para a interface gráfica.

Após a versão 4.0, uma área de desenvolvimento será revisar a presença visual, isto é a interface do usuário, do QualCoder. O objetivo é tornar a interface mais moderna e atraente. Outra área de melhoria será fornecer mais documentação de governança, para apoiar o uso do QualCoder em grandes instituições.

## Sistemas operativos utilizados

O QualCoder foi usado no Windows 11, macOS, Ubuntu 24, Lubuntu, Fedora, Linux Mint, Arch Linux, Fedora, NixOS e ZorinOS.

* Usar áudio ou vídeo com o QualCoder no Fedora faz o QualCoder quebrar.
* Debian com o Gnome e a opção de janela em _tiling_ - encolhe o tamanho da janela QualCoder. A melhor opção é desligar o _tiling_ de janelas nas configurações do Gnome.

## Estruturas de dados

**A pasta de projeto qda** contém pastas para documentos importados e o banco de dados sqlite para armazenar os dados de codificação. Quando a IA está ativada, há uma pasta `ai_data` contendo um banco de dados sqlite com o histórico de conversas e uma _vectorstore_. Uma _vectorstore_ é uma representação numérica de palavras, frases e orações usada pelo modelo de linguagem de IA.

**A pasta de trabalho `.qualcoder`** em sua pasta _home_. O QualCoder cria o arquivo `QualCoder.log` e arquivos de configuração. Não coloque nenhum arquivo dentro desta pasta, pois ela é usada como uma área de configurações e armazenamento de trabalho do QualCoder. A **pasta `.qualcoder_ai`** na pasta _home_ contém os detalhes de configuração para o uso da IA.
