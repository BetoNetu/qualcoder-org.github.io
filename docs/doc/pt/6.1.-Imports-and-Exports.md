## Exportar livro de códigos (_codebook_) 

Esta é uma opção no Menu Projeto > Exportações.

Um livro de códigos (ou _codebook_) é uma lista dos seus códigos. Cada memorando de código deve especificar as razões para a finalidade de cada código. O livro de códigos pode ser exportado para um arquivo de texto. O livro de códigos também mostra a frequência dos códigos utilizados (de todos os codificadores). Uma vez que os códigos e categorias são colocados numa estrutura semelhante a uma árvore, o travessão/'menos duplo' ("–") indica os códigos e categorias subordinados dentro de uma categoria.

## Importação do _codebook_

Importe um livro de códigos como um arquivo de texto simples (.txt) ou como um arquivo .csv. Use dois símbolos de "maior que" (>>) para separar categorias e códigos. Use três símbolos "maior que" (>>>) para definir um código sob um código.

### Texto simples

Use a aba para adicionar um memorando.
```
code1

category1>>category2>>code2	memo

category1>>code3

category3>>code4

code5>>>code6>>>code7
```

### CSV

As categorias e códigos estão na primeira coluna. Quaisquer memorandos de código estão na segunda coluna.
```
code1

category1>>category2>>code2

category3>>code3
```

## REFI-QDA
A [Iniciativa Formato de Intercâmbio de Roterdã (em inglês _Rotterdam Exchange Format Initiative_ - REFI)](https://www.qdasoftware.org) é um padrão aberto para exportação e importação de _codebooks_ e projetos de e para diferentes _softwares_ de análise de dados qualitativos assistidos por computador.

Atualmente, o QualCoder é capaz de importar um codebook desde que esteja usando a versão "urn:QDA-XML:codebook:1.0". O QualCoder também exporta nesta versão.

A exportação de um projeto e a importação de um projeto são funcionais. Ainda não estou preparado para garantir que ele cumpre plenamente o padrão REFI-QDA - particularmente alguns aspectos áudio/vídeo. Algumas experiências foram realizadas com arquivos de projeto Nvivo, Atlas.ti, Quirkos e MAXQDA REFI QDA. Importação para MAXQDA parece exigir um caractere adicional de fim de linha sobre codificação de texto - esta é uma opção na exportação de projeto REFI-QDA da QualCoder. Importar para o Atlas.ti mudou os códigos por um caractere após cada linha terminar, e ainda não foi resolvido. A importação de atributos da QualCoder não funciona para Atlas.ti, MAXQDA, atributos de caso não foram importados para Quirkos.

Características como conjuntos e gráficos não podem ser importados, pois tal funcionalidade não está dentro do QualCoder. Outros formatos de dados não são preservados, por exemplo data ou booleano serão convertido para dados de texto.

Para áudio e vídeo, a importação de transcrições e pontos de sincronização não é testada. A importação/ligação de arquivos ligados de modo relativo não foi testada.

Para importar, feche primeiro qualquer projeto aberto atualmente. Em seguida, escolha um novo nome do projeto QualCoder e selecione o arquivo de importação qdpx.

Se nenhum dado codificado estiver visível, você pode precisar alterar o nome do codificador atual em Configurações. Tenta a caixa de nomes do codificador.

Este rescuro é antigo (Fev 2021), mas um usuário testou a importação de um arquivo de projeto REFI-QDA gerado pela QualCoder e importado para MAXQDA, Quirkos, Atlas.ti. Apenas texto e imagens foram testados. Um PDF dos resultados do teste está aqui:[Teste de importação de arquivos do projeto REFI-QDA para Atlas, MAXQDA, Quirkos PDF](https://qualcoder.files.wordpress.com/2021/02/refi-qda-project-import-quirkos-maxqda-atlas.pdf)

## Taguette

Projetos criados com o [Taguette](https://www.taguette.org/) podem ser importados diretamente. Todos os seus dados de codificação serão transferidos.

Feche qualquer projecto aberto. Em seguida, no Menu Principal do Projeto, clique em "Importar projeto do Taguette". Você será solicitado a criar um novo projeto, então digite um nome. Em seguida, você será solicitado a selecionar o arquivo de projeto Taguette (geralmente com uma extensão `.sqlite3`). O QualCoder irá então proceder à importação.
Se quaisquer dados codificados não vierem, poderá ser preciso alterar o nome do codificador atual nas Definições. Tente usar o nome do codificador.

## Sonal π (Solal Pi)

## RQDA

Projetos realizados com o [RQDA](http://rqda.r-forge.r-project.org/) podem ser importados diretamente. Todos os dados, exceto as categorias de arquivos, são importados.

Feche qualquer projecto aberto. Em seguida, no Menu Principal em Projeto clique em "Importar projeto do RQDA". Você será solicitado a criar um novo projeto - então digite um nome. Então você será solicitado a selecionar o arquivo de projeto RQDA. O QualCoder irá então importar os dados.

Se nenhum dado codificado estiver visível, você pode precisar alterar o nome do codificador atual em Configurações. Tente a caixa de nomes do codificador.

## Ajuda - Funções Especiais

### Conteúdo de texto de atualização dinâmica

Isso é útil para atualizar arquivos de texto, como extratos de posts do blog, que mudam ao longo do tempo. Atualize um arquivo de texto enquanto tenta manter os segmentos de texto codificados existentes. Selecione o arquivo de texto que precisa ser substituído e selecione o arquivo de substituição. Clique no botão engrenagens para executar a atualização. Esta função funciona encontrando o texto correspondente idêntico no arquivo de substituição como ele analisa através do texto do arquivo. Pode produzir segmentos erroneamente codificados.
