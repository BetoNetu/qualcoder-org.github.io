# Criar um Novo Projecto

Você pode **criar um novo projeto no menu ‘Projeto’.**

Se você nomeá-lo "Teste", o projeto será salvo como Test.qda. Test.qda é na verdade uma pasta com subpastas contendo o banco de dados, documentos empíricos e outros arquivos. Se você quiser enviar o projeto por e-mail para outra pessoa, compacte a pasta inteira.

## Tela principal {#main-screen}

A aba Registro de Ações na janela principal exibe várias alterações que são feitas ao usar o QualCoder. A janela principal tem uma barra de menu no topo cheia de opções. Existem cinco abas para:  Registro de Ações ,  Gerenciar ,  Relatórios,  Codificação  e  Chat de IA . Mudar diretamente entre as abas é geralmente OK. Mas se você estiver adicionando, renomeando, excluindo arquivos em Gerenciar Arquivos ou alterando códigos ou categorias de código na área Codificação, é melhor atualizar cada guia selecionando a opção relevante na barra de menu no topo da tela. Por exemplo, alterar arquivos em Gerenciar arquivos, em seguida, fazer codificações ou relatórios - selecione uma opção no Menu para codificação ou relatório, em vez de clicar diretamente na guia para codificação ou relatórios. Isto acontece porque algumas alterações no gerenciamento do banco de dados podem não ter atualizado atualizar.

![imagem](/images/dcb4d4e7-a39b-424b-84c4-d2915098914f.png)


**Não execute seu projeto a partir de uma localização na nuvem** (OneDrive, Dropbox, etc.). As razões são: às vezes os arquivos não podem ser importados para o projeto. Acessar um projeto armazenado na nuvem de diferentes computadores é especialmente perigoso, pois pode causar problemas de sincronização e até corromper o banco de dados. Veja [esta página para estratégias seguras para trabalhar em equipe e em vários computadores](2.4.-Working-in-a-Team). Da mesma forma, **Não execute seu projeto a partir de um _pendrive_ USB (_flash_)**, pois o banco de dados pode ser corrompido.

!!! tip "Boas práticas de gestão de dados"
    Para qualquer projeto, mantenha boas práticas de gerenciamento de dados, como ter _backups_ armazenados regularmente e, idealmente, armazenados em diferentes locais (por exemplo, nuvem, pastas de computador diferentes, discos rígidos, _pendrives_).

## Escreva um memorando de projeto {#write-a-project-memo}

Isto é **especialmente importante se você quiser usar os recursos baseados em IA** no QualCoder. O memorando do projeto é usado para fornecer algumas informações contextuais sobre o projeto atual e o tipo de documentos empíricos com os quais estamos lidando. Essa informação, a qual está incluída em cada _prompt_, ajuda a IA a produzir respostas muito mais direcionadas e úteis. Você pode acessar o Memorando do Projeto em Memorando > Memorando do Projeto.

![Imagem Exemplo do Memorando do Projeto.](/images/c4c44cbe-9195-4cd3-a1f6-e9efccceb45d.png)

O QualCoder fornece um modelo para as informações mais importantes. Você não precisa seguir esse modelo exatamente, mas tente **manter a descrição do projeto curta** (entre 300 e 700 caracteres). Você também pode adicionar notas sobre seu referencial teórico, mas tenha cuidado para não "pré-formatar" demais a perspectiva da IA.

Se você também quiser usar o memorando do projeto para outras notas que não devem ser compartilhadas com a IA, você pode inserir a _tag_ "######" no texto. Qualquer coisa abaixo dessa marca não será enviada para a IA (isso funciona em qualquer memorando em QualCoder).

Se não quiser que o memorando do projeto seja enviado para a IA, desactive-o na janela de Configurações.
