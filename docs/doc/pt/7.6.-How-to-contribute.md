# Como contribuir

## Contribua com o código {#contributing-to-the-code}

Por favor leia as [diretrizes de contribuição](https://github.com/ccbogel/QualCoder/blob/master/docs/CONTRIBUTING.md)

### Regras principais em resumo {#key-rules-at-a-glance}

- **Escolha primeiro uma issue.** Procure uma issue existente ou crie uma, e comente nela antes de abrir um Pull Request. Aguarde até que a issue seja atribuída a você antes de começar a trabalhar.
- **Um Pull Request, um commit.** Reúna (squash) seu trabalho em um único commit com uma mensagem descritiva que reflita suas alterações.
- **Nomenclatura.** Crie um branch dedicado com o nome da issue que você está tratando.
- **Licença.** Ao enviar um Pull Request, você licencia sua contribuição sob a licença LGPLv3 do projeto ("Inbound = Outbound").

### Contribuições assistidas por IA {#ai-assisted-contributions}

Você pode usar ferramentas de IA para auxiliar suas contribuições, mas você permanece totalmente responsável por tudo o que enviar.

- **Entenda**: você deve ser capaz de explicar cada linha do seu código.
- **Teste**: código gerado por IA deve passar por todos os testes e verificações de segurança.
- **Declare**: escolha um nível de assistência de IA (0–5) no modelo de Pull Request.
- **Assuma**: você é o autor. Se um revisor perguntar "por quê?", quem responde é você — não a IA.

Ferramentas de IA **não** devem ser usadas para corrigir issues rotuladas `good first issue`. Elas existem para o aprendizado humano.

## Contribua para a tradução {#contribute-to-the-translation}

### Traduza a documentação {#translate-the-documentation}

Você pode traduzir a documentação criando/modificando os arquivos _Markdown_ (.md) em `docs/doc` [no repositório do site](https://github.com/QualCoder-Org/qualcoder-org.github.io).

### Traduza o software {#translate-the-software}

O QualCoder suporta a funcionalidade multilíngue usando dois tipos de arquivos de tradução:

- Arquivos Gettext (.po ou .mo), que contêm a tradução do software;
- Arquivos de idioma QT (.ts ou .qm) correspondentes à interface do usuário.

Para traduzir:

1. Crie um arquivo de idioma (se ainda não existir) usando este comando:
```python rebuild_lang.py --create --lang LANGUAGE_CODE```
Por favor, note que os nomes dos seus arquivos de idioma devem seguir o formato [ISO 639-1](https://fr.wikipedia.org/wiki/Liste_des_codes_ISO_639-1).

2. Se um arquivo de idioma já existe, você pode atualizar as traduções usando
```python rebuild_lang.py --update --lang LANGUAGE_CODE```.

3. Você pode editar as traduções dos arquivos .po e .ts na pasta src/i18n usando o [Poedit](https://poedit.net/).

4. Uma vez que o trabalho esteja concluído, compile-o para o formato de máquina usando este comando:
```python rebuild_lang.py --compile --lang LANGUAGE_CODE```.

***

> A tradução em Português é mantida por um brasileiro de maneira **voluntária**. Qualquer problema, imprecisão ou questão com a **tradução**, contate [BetoNetu](https://github.com/BetoNetu)
