# Como contribuir

## Contribua com o código

Por favor leia as [Orientações para as contribuições (em inglês)](https://github.com/ccbogel/QualCoder?tab=contributing-ov-file)

## Contribua para a tradução
### Traduza a documentação

Você pode traduzir a documentação criando/modificando os arquivos _Markdown_(,md) em `docs/doc` [no repositório do site](https://github.com/QualCoder-Org/qualcoder-org.github.io).

### Traduza o software

QualCoder suporta a funcionalidade multilingue usando dois tipos de arquivos de tradução:

- Arquivos Gettext (.po ou .mo), que contêm a tradução de software;
- Arquivos de idioma QT (.ts ou .qm) correspondentes à interface do usuário.

Para traduzir:

 1. Crie um arquivo de idioma (se já não existir) usando este comando:```python rebuild_lang.py --create --lang LANGUAGE_CODE``` Por favor, note que os nomes dos seus arquivos de idioma devem seguir formato [ISO 639-1](https://fr.wikipedia.org/wiki/Liste_des_codes_ISO_639-1).
 2. Se um arquivo de idioma já existe, você pode atualizar as traduções usando```python rebuild_lang.py --update --lang LANGUAGE_CODE```.
 3. Você pode editar as traduções dos arquivos .po e .ts na pasta src/i18n usando o [Poedit](https://poedit.net/).
 4. Uma vez que o trabalho esteja concluído, compile-o para o formato de máquina usando este comando:```python rebuild_lang.py --compile --lang LANGUAGE_CODE```.

***
> A tradução em Português é mantida por um brasileiro de maneira **voluntária**, qualquer problema, imprecisão ou questão com a **tradução** contate [BetoNetu](github.com/BetoNetu)
