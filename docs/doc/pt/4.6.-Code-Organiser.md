# Organizador de Códigos

O organizador de códigos permite alterar a estrutura da árvore de codificação.

Quando você abrí-lo pela primeira vez, você será solicitado a fazer _backup_ do seu projeto antes de fazer ou aplicar quaisquer alterações. As alterações feitas aqui não podem ser desfeitas.

![imagem](/images/ae81b366-54e8-457f-9afe-abb7f76d2a41.png)

Usando o botão mais à esquerda, selecione todos os ramos de códigos em seu projeto, ou apenas um ramos de códigos específico.

![imagem](/images/57b82319-1145-4872-a6c7-63cbc807b370.png)

Todas as subcategorias e códigos da sua seleção serão exibidos.

![imagem](/images/303ddd26-605c-4963-9db4-ba7c50c40250.png)

**Códigos:**

Clique com o botão direito do _mouse_ em um código para obter opções: remover da categoria, mover para outra categoria, Mesclar em outro código, Visualizar/editar o memorando, renomear, visualizar a mídia codificada, exibir o memorando sob o nome do código.

**Categorias:**

Existe um botão no topo da tela para adicionar uma nova categoria.

Clique com o botão direito em uma categoria para: mesclar uma categoria em outra categoria, mover uma categoria para outra categoria, remover uma categoria sob outra categoria, renomear uma categoria, visualizar e editar memorando, ou apenas exibir o memorando sob o nome da categoria.

Mostrando o memorando sob o nome da categoria

![imagem](/images/92fee31b-1b70-4bdf-bb15-51b0485e4739.png)

Existe um botão para exportar a imagem como um arquivo PNG.

O botão Aplicar faz as alterações na estrutura da árvore de codificação. Se não pressionado, as mudanças não ocorrem de fato.
