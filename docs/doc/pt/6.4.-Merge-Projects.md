# Mesclar Projetos no QualCoder

Vá para o menu Ajuda e selecione Funções Especiais:

![image](/images/gh-67505afd-aa23-4fde-a663-07738e070034.png)

Selecione um projeto QualCoder para mesclar (o projeto fonte) no projeto atualmente aberto, o projeto de destino.

![imagem](/images/gh-f0804921-e5c1-429e-866f-4b3a456a0396.png)[imagem]

Em seguida, clique no botão _Executar mescla de projetos_. ![image](/images/gh-f6acdd75-1f89-4d05-b366-39ec4811b135.png)[imagem]



**Antes de executar a mesclagem, faça um _backup_ do projeto de destino.**

Atenção: Se cada projeto a ser mesclado tiver o mesmo nome de codificador, por exemplo, 'padrão', então eles irão se mesclar como tal, e você não será capaz de separar qual codificador realizou sua própria codificação. Esta pode ou não ser uma consideração importante para o seu projeto final mesclado.

O seguinte ocorre:

* Copia arquivos incomparáveis das pastas de projeto de origem para as pastas de projeto de destino.
* Adiciona novas categorias de origem (não iguais) ao banco de dados de destino.
* Adiciona nomes de código- fonte novos (sem correspondência) ao banco de dados de destino.
* Adiciona diários e armazenamento sql ao banco de dados de destino, somente se tiverem nomes que não correspondam aos nomes de destino existentes.
* Adiciona codificação de texto, anotações de texto, codificação de imagem, codificação A/V ao banco de dados de destino.
* Adiciona casos e case text (links de casos para segmentos de arquivos de texto e imagens e A/V).
* Adicionar atributos para arquivos e casos.
* Adiciona valores de atributos. Os valores dos atributos de destino existentes não são sobrescritos, a menos que estejam em branco.

!!! info "Considerações antes de mesclar"
    Idealmente, todos teriam os mesmos arquivos idênticos dentro do projeto.
    Idealmente, usando o mesmo conjunto de nomes de código - mas isso poderia ser trabalhado em torno mais tarde se mesclar ou renomear códigos ocorreu no projeto coligido.
    Nomes de codificador - precisaria ser único para cada codificador. Assim, ao coligir, o trabalho de cada codificador pode ser identificado.
    Alternativamente, os nomes do codificador poderiam ser os mesmos, desde que cada codificador trabalhasse em arquivos únicos. Mas isso depende dos seus objectivos finais. Se você teve a necessidade de coligir tudo sob um nome codificador.

!!! warining "Avisos ao mesclar"
    O aviso principal é se o projeto de origem e o projeto de destino contiverem o mesmo arquivo de texto. Se o arquivo de texto do projeto de origem foi editado, e pode ser mais longo ou mais curto, então as posições de codificação de texto importadas e anotações serão incorretas. Isto ocorre porque o texto original do arquivo de texto do projeto de destino armazenado no banco de dados não é substituído pelo arquivo de texto editado do projecto de origem.
