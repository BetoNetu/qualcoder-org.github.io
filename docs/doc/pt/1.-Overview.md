# Visão geral

As instruções descrevem como instalar e usar o QualCoder. As informações aqui referem-se à versão mais recente do QualCoder.

## O que é o QualCoder? {#what-is-qualcoder}

O QualCoder é um software livre e de código aberto para análise de dados qualitativos. Com o QualCoder você pode codificar texto, imagens, áudio e vídeo, escrever notas de diário e memorandos. Você pode organizar códigos em um esquema de categorização em árvore. Vários tipos de relatórios podem ser gerados. A maioria dos relatórios pode ser exportada como html, texto de documento aberto (ODT), texto simples ou arquivos de Excel (XLSX).

Versões recentes contêm recursos opcionais auxiliados por IA que usam GPT-4 ou outros modelos de linguagem em larha escala para ajudar a explorar, analisar e interagir com dados de formas inovadoras. Familiarize-se com novos dados ao[explorar tópicos ou conceitos amplos](5.1.-AI-chat-based-analysis#topic-analysis-chat) numa conversa interactiva com a IA. Aprofunde-se em aspectos específicos com a [Codificação auxiliada por IA](4.2.-AI-Assisted-Coding)e[análise de texto](5.1.-AI-chat-based-analysis#text-analysis-chat). E se você chegar ao ponto onde você deve sintetizar e consolidar seus resultados,[dicuta-os em um chat de código](5.1.-AI-chat-based-analysis#code-analysis-chat) com a IA.

O QualCoder é projetado para ser usado como [software baseado em cliente](https://pt.wikipedia.org/wiki/Cliente_(computa%C3%A7%C3%A3o)) para ser usado por uma pessoa de cada vez. (Um segundo codificador pode usar o mesmo projeto no mesmo computador, ou a pasta do projeto pode ser transferida para o computador do segundo codificador).O  QualCoder não é projetado para ser acessado por mais de um usuário ao mesmo tempo. Acessar/Abrir o projeto em uma localização na nuvem não é recomendado, isso pode corromper o banco de dados se a conexão de banco de dados for perdida durante qualquer processo de atualização de banco de dados.
