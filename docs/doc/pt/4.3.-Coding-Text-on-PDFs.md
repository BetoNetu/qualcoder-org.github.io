# Codificar PDFs

As áreas de texto e imagem no PDF podem ser codificadas.

![imagem](/images/ba02d9ee-24fe-4b67-84b0-4f62cd62a1c6.png)


### Atalhos de teclas {#key-presses}

* H Mostrar ou ocultar as seções superiores da tela.
* Ctrl + F salta para a caixa de pesquisa de texto.
* Ctrl + Z desfaz o último código não marcado.
* Ctrl + 1 Ir para o arquivo seguinte.
* Ctrl + 2 Ir para o último arquivo codificado.
* Ctrl + 4 Ver e editar o memorando do arquivo.
* Ctrl + 5 Obter a lista de arquivos dos atributos.
* Ctrl + 9 Mostrar segmentos codificados importantes. Liga/desliga.
* Ctrl + 0 Mostrar página de ajuda no navegador.

#### Na área de exibição PDF: {#in-the-pdf-display-area}

Você pode aumentar ou diminuir o zoom clicando no PDF mostrado e pressionando as teclas + ou -.
Pressione Q para marcar rapidamente a seleção com o código mais recente.
Pressione R para marcar rapidamente a seleção com uma escolha de códigos usados recentemente.

#### Na área de texto simples: {#in-the-plain-text-area}

* A Anotação - para a seleção atual - apenas edição de texto
* Q Marcação rápida com código - para a seleção atual
* I Marcar como importante
* M Codificar memorando - na posição clicada
* O Atalho para iterar através de códigos sobrepostos - na posição clicada
* R abre um menu de contexto para códigos usados recentemente para marcar texto
* U Desmarcar na localização selecionada
* V atribuir código '_in vivo_' ao texto selecionado

## Exportar Relatórios {#export-reports}
Exportar em formato odt - compatível com LibreOffice e Microsoft Word. Ou como um PDF com destaque aplicado.

## Versões mais antigas 3.8.2 e anteriores {#older-versions-382-and-earlier}

A tela é dividida em 3 painéis ajustáveis. O painel do lado esquerdo contém a lista de arquivos e a árvore de códigos. O painel médio mostra a representação em PDF. O painel direito mostra o texto simples extraído do PDF. As fontes originais para o texto não são usadas. Em vez disso, a fonte padrão dentro do QualCoder é usada nas caixas de texto PDF exibidas. Existe um ajuste de tamanho de fonte para diminuir o tamanho da fonte, para tentar evitar sobreposição de texto. É definido em -2; e -3 pode ser muito bom também.

O painel do lado direito mostra o texto simples da mesma forma que o texto seria exibido em Codificar Texto. Você pode marcar, desmarcar, ou gerar um memorando (a)o texto codificado, marcar o código como importante e criar anitações de texto aqui.

Para codificar, clique com o botão esquerdo e arraste o mouse para selecionar caixas de texto PDF. Isso pode ser complicado dependendo do tamanho e das posições das caixas. Em seguida, clique em um código para atribuir a seleção a ele. Outros ajustes podem ser feitos no painel de texto simples à direita usando Shift + setas esquerda ou direita para estender, ou Alt + setas esquerda e direita para encolher o trecho de texto codificada.
